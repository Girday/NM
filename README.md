# Численные методы

Лабораторные работы по курсу «Численные методы» (МАИ, кафедра 806). Вариант № 7.

## Запуск

Нужен Python 3. Из корня репозитория создайте виртуальное окружение и установите зависимости.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install numpy matplotlib
```

В Windows PowerShell для создания окружения используйте `py -3 -m venv .venv`, а для активации — `.\.venv\Scripts\Activate.ps1`.

Запустите нужный скрипт из корня репозитория. Например, `python lab3/task3.py`. Данные варианта и параметры вычислений заданы в скриптах. Результаты выводятся в терминал. Задания 2.1, 2.2 и 3.3 также открывают окно с графиками.

## Лабораторные работы

### ЛР 1. Численные методы линейной алгебры

[Условия заданий 1.1–1.5](materials/labs/lab1/)

| Задание | Что вычисляется | Как проверяется |
| --- | --- | --- |
| [1.1](lab1/task1.py) | Решение СЛАУ, определитель и обратная матрица через LU-разложение с выбором главного элемента по столбцу | `P @ A ≈ L @ U`, `A @ x ≈ b`, `A @ A_inv ≈ I` |
| [1.2](lab1/task2.py) | Решение трёхдиагональной СЛАУ методом прогонки | Невязка, сравнение с методом Гаусса с выбором главного элемента и проверка достаточного условия устойчивости |
| [1.3](lab1/task3.py) | Решение СЛАУ методом простых итераций и методом Зейделя | Невязка, оценка погрешности и число итераций при разных значениях точности |
| [1.4](lab1/task4.py) | Собственные значения и векторы симметричной матрицы методом вращений Якоби | Невязки собственных пар, ортогональность векторов и изменение критерия остановки и невязки с числом вращений |
| [1.5](lab1/task5.py) | QR-разложение отражениями Хаусхолдера и поиск собственных значений QR-алгоритмом без сдвигов, включая комплексные пары | `Q @ R ≈ A`, ортогональность `Q`, треугольность `R`, сравнение собственных значений с NumPy и их суммы со следом матрицы |

NumPy используется в заданиях 1.1, 1.4 и 1.5 для матричных операций и проверок. Задания 1.2 и 1.3 запускаются со стандартной библиотекой Python. Точность в заданиях 1.3–1.5 задаётся в `main()`. У QR-алгоритма без сдвигов достижение заданной точности зависит от входной матрицы.

### ЛР 3. Приближение функций, численное дифференцирование и интегрирование

[Условия заданий 3.1–3.5](materials/labs/lab3/)

| Задание | Что вычисляется | Как проверяется |
| --- | --- | --- |
| [3.1](lab3/task1.py) | Интерполяционные многочлены Лагранжа и Ньютона для двух наборов узлов | Совпадение значений в узлах и абсолютная погрешность в точке `X* = 3` |
| [3.2](lab3/task2.py) | Естественный кубический сплайн и его значение в точке `X* = 3` | Совпадение с таблицей, непрерывность первой и второй производных на стыках, нулевая кривизна на концах |
| [3.3](lab3/task3.py) | Приближающие многочлены первой и второй степеней методом наименьших квадратов | Невязка нормальной системы, сравнение сумм квадратов ошибок и графики с табличными точками |
| [3.4](lab3/task4.py) | Первая и вторая производные в точке `X* = 0.2` по трём соседним узлам | Сравнение с производными `arccos(x)`, значения которой при округлении совпадают с таблицей |
| [3.5](lab3/task5.py) | Определённый интеграл методами средних прямоугольников, трапеций и Симпсона | Оценка Рунге–Ромберга и сравнение с точным значением интеграла |

Для графиков в задании 3.3 нужен Matplotlib. В задании 3.5 шаги `h1 = 1.0` и `h2 = 0.5` задаются в `main()`. На этих шагах поправка Рунге–Ромберга увеличивает фактическую погрешность всех трёх методов.
