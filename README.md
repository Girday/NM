# Численные методы

Лабораторные работы по курсу «Численные методы», МАИ, кафедра 806.
Вариант № 7.

Каждое задание оформлено отдельным Python-скриптом с исходными данными,
реализацией метода и выводом результатов.

## Лабораторная работа № 1

| Задание | Метод и результат | Код |
| --- | --- | --- |
| 1.1 | LU-разложение с выбором главного элемента по столбцу: решение СЛАУ, определитель и обратная матрица | [task1.py](lab1/task1.py) |
| 1.2 | Метод прогонки для трёхдиагональной СЛАУ | [task2.py](lab1/task2.py) |
| 1.3 | Метод простых итераций и метод Зейделя: решение СЛАУ и сравнение числа итераций при разной точности | [task3.py](lab1/task3.py) |
| 1.4 | Метод вращений Якоби: собственные значения и векторы симметрической матрицы, история сходимости | [task4.py](lab1/task4.py) |
| 1.5 | QR-разложение отражениями Хаусхолдера и QR-алгоритм поиска собственных значений, включая комплексные пары | [task5.py](lab1/task5.py) |

Алгоритмы реализованы в коде явно. NumPy используется в заданиях 1.1,
1.4 и 1.5 для операций с матрицами, форматирования и проверок;
в задании 1.5 библиотечный поиск собственных значений служит независимой проверкой.
Задания 1.2 и 1.3 используют только стандартную библиотеку Python.

```bash
python3 lab2/task1.py
```

Скрипты печатают результаты, невязки и погрешности по шагам, затем открывают

## Запуск лабораторной работы № 1

Нужны Python 3 и NumPy. Из корня репозитория создайте виртуальное окружение
и установите зависимость:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install numpy
```

В Windows вместо `source` используйте `.venv\Scripts\Activate.ps1`
в PowerShell.

Запустите нужное задание:

```bash
python lab1/task1.py
python lab1/task2.py
python lab1/task3.py
python lab1/task4.py
python lab1/task5.py
```

Результаты выводятся в терминал. Ввод с клавиатуры и аргументы командной
строки не требуются: данные варианта заданы внутри скриптов.
В `task1.py` матрица `A` и вектор `b` находятся в начале файла;
в остальных заданиях исходные данные находятся в функции `main()`.
Точность `eps` для заданий 1.3–1.5 также задаётся в `main()`.

## Проверка результатов

При запуске скрипты выводят следующие проверки:

- **1.1:** восстановление `P @ A ≈ L @ U`, подстановка `A @ x ≈ b`
  и произведение `A @ A_inv ≈ I`.
- **1.2:** невязка системы и сравнение с методом Гаусса с выбором главного элемента;
  отдельно проверяется достаточное условие устойчивости прогонки.
- **1.3:** невязка, оценка погрешности и число итераций для нескольких значений точности.
- **1.4:** невязки собственных пар `A v − λ v`, ортогональность векторов
  и зависимость критерия остановки и невязки от числа вращений.
- **1.5:** восстановление `Q R ≈ A`, ортогональность `Q`, треугольность `R`,
  сравнение собственных значений с NumPy и их суммы со следом матрицы.

Итерационные методы предусматривают ограничение числа итераций.
Для QR-алгоритма используется схема без сдвигов; достижение заданной точности
для произвольной входной матрицы не гарантируется.
